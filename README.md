# ClearTax Bulk Invoice Processing — Frontend

A modern, responsive frontend for **ClearTax's Bulk Invoice Processing System**, designed to make large-scale invoice uploads simple, transparent, and easy to track.

The application allows users to upload invoices in **CSV format**, monitor the processing progress in real time, and view the results in an organized, scrollable table. Each invoice is processed independently, so a failed invoice does not interrupt the processing of the remaining invoices.

### Key Frontend Features

* 📄 **CSV Invoice Upload** — Upload bulk invoice data through a simple interface.
* 📊 **Processing Progress** — Track the number and percentage of invoices processed.
* ✅ **Match/Mismatch Status** — Clearly identify successfully matched and mismatched invoices.
* ❌ **Row-Level Errors** — Display errors against the specific invoice that failed.
* 📋 **Scrollable Results Table** — Easily review large numbers of processed invoices.
* 📱 **Responsive Interface** — Designed to work smoothly across desktop and smaller screens.

The frontend focuses on providing a **clean, intuitive, and informative dashboard experience** while keeping users aware of the processing status and any issues encountered during invoice processing.
